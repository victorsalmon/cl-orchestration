# cl-claude - runbooks about how Claude works

This family holds procedures and lessons that are about **Claude as the
executor**: what the parent can and cannot do, how it dispatches lanes, how it
hands work to a hub. A rule every executor must follow belongs in the fleet
skill that owns the surface (`git-operations`, `cl-beads`, `paseo-child-agents`,
`iqa-merge-runner`); this family points at those owners and never restates them.

## Which member for which task

| Task | Member | Canonical path |
| :--- | :--- | :--- |
| `/omnicode`: claim beads, run them in parallel on worktrees, batch-merge them, send the hub a high-priority "merge this next" | `omnicode` | `$env:CL_REPOS_ROOT\cl-common\vendor\cl-orchestration\cl-claude\skills\omnicode\SKILL.md` |
| Hand bounded work to Paseo OpenCode Go workers with round-robin keys (what Claude does differently; points at the Paseo owners) | `opencode-go-dispatch` | `$env:CL_REPOS_ROOT\cl-common\vendor\cl-orchestration\cl-claude\skills\opencode-go-dispatch\SKILL.md` |
| Look up or record a Claude-specific lane lesson (dispatch, notifications, handover, memory) | `claude-lane-lessons` | `$env:CL_REPOS_ROOT\cl-common\vendor\cl-orchestration\cl-claude\skills\claude-lane-lessons\SKILL.md` |

## Disambiguation

- **`cl-claude` vs `Executors/`.** `Executors/<EXECUTOR>/` is the per-executor
  self-improvement tree (contract: `Skills/Executors/README.md`). This family is
  the Claude-facing front door: a lesson recorded here that turns out to be true
  for every executor is promoted into the owning fleet skill and leaves one
  pointer behind.
- **`cl-claude` vs `cl-beads` / `cl-paseo`.** Those run the beads graph and the
  agent fleet. `omnicode` is one interactive session doing the whole loop once
  for a named bead set, ending in a hand-over to the hub, never a merge.

## Red lines

- **Never ask permission to start lanes**: announce them and start them.
- **Never merge, deploy or override a lock yourself**; hand the hub a request.
- **Never bypass hooks** (`--no-verify`, `core.hooksPath` edits) or touch files
  you did not author.
